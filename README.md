# Программная часть ВКР: моделирование устойчивости логистической сети

Репозиторий содержит программную часть выпускной квалификационной работы, посвящённой моделированию логистической сети и анализу её поведения в штатном режиме, при атаке и при применении защитных мер.

## Назначение проекта

Проект моделирует движение материального потока по цепочке:

supplier → warehouse → hub → client

Дополнительно учитывается финансовый контур через узел bank.  
Модель позволяет сравнивать три сценария:

- `normal` — штатная работа системы;
- `attack` — нарушение работы логистической сети;
- `protection` — применение защитных мер.

## Состав проекта

- `model_spec.json` — описание структуры модели, узлов сети и сценариев.
- `simulation.py` — исходная версия программы моделирования.
- `simulation_improved.py` — улучшенная версия программы с доработанными параметрами.
- `results.csv` — результаты исходной версии модели.
- `results.png` — график исходной версии модели.
- `results_improved.csv` — результаты улучшенной версии модели.
- `results_improved.png` — график улучшенной версии модели.
- `supply_chain_schema_simple_final.py` — скрипт для построения схемы цепочки поставок.
- `supply_chain_schema_simple.png` — готовая схема цепочки поставок.
- `supply_chain_schema_simple.png.meta.json` — метаданные изображения.

## Требования

Для запуска необходимы:

- Python 3.10 или выше;
- библиотеки:
  - `pandas`
  - `simpy`
  - `networkx`
  - `matplotlib`
  - `numpy`

## Установка

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск модели

Запустите основную программу:

```bash
python simulation_improved.py
```

После выполнения будут сформированы:

- `results_improved.csv`
- `results_improved.png`

## Построение схемы

Для генерации схемы цепочки поставок запустите:

```bash
python supply_chain_schema_simple_final.py
```

После выполнения будет создан файл:

- `supply_chain_schema_simple.png`

## Интерпретация файлов

- CSV-файлы содержат числовые результаты моделирования по сценариям.
- PNG-файлы содержат графическую интерпретацию результатов.
- Скрипты `.py` позволяют воспроизвести расчёты и построение схемы.
- JSON-файл содержит параметры модели и сценарные настройки.
